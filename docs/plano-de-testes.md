
Plano de Testes — E-commerce

1. Identificação do projeto

- Projeto: QA Manual — E-commerce
- Aplicação: SauceDemo
- Tipo de teste: Testes manuais funcionais
- Responsável: Bruno Castro
- Status: Em andamento

2. Objetivo

Validar as principais funcionalidades de uma aplicação de e-commerce, verificando se os comportamentos observados correspondem aos resultados esperados.

3. Escopo dos testes

Serão avaliadas as seguintes funcionalidades:

- Autenticação e login
- Exibição e navegação dos produtos
- Ordenação dos produtos
- Adição e remoção de itens do carrinho
- Conferência dos itens no carrinho
- Preenchimento dos dados de entrega
- Resumo e finalização da compra

4. Tipos de teste

- Testes funcionais
- Testes negativos e de validação
- Testes exploratórios
- Testes de fluxo de compra

5. Ambiente de teste

- Aplicação: https://www.saucedemo.com/
- Navegador: A registrar durante a execução
- Sistema operacional: A registrar durante a execução
- Data de execução: A preencher

6. Critérios de entrada

- Aplicação acessível
- Cenários de teste documentados
- Ambiente de teste disponível

7. Critérios de saída

- Casos planejados executados ou com impedimento documentado
- Resultados registrados
- Defeitos encontrados documentados com evidências, quando aplicável

8. Riscos e limitações

- A aplicação é destinada a demonstrações e testes.
- O comportamento pode variar conforme o usuário de demonstração utilizado.
- Os resultados deste documento não representam testes já executados.

9. Entregáveis

- Plano de testes
- Casos de teste
- Relatórios de defeitos
- Evidências de execução
- Relatório final de resultados
